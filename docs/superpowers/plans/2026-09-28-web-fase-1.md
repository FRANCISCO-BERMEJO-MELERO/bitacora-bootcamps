# Web de la Bitácora (Fase 1): plan de implementación

> **Para agentes:** ejecución nativa (superpowers:executing-plans). Pasos con casillas `- [ ]`.

**Objetivo:** dejar la web Astro funcionando con un bootcamp y un apunte de prueba.

**Arquitectura:** sitio estático Astro con dos colecciones (JSON y Markdown), tres rutas,
componentes pequeños y estilos con Tailwind v4 más tokens CSS propios.

**Stack:** Astro 7.3, Tailwind 4.3 (`@tailwindcss/vite`), Mermaid 12.

**Spec:** `docs/superpowers/specs/2026-09-28-web-fase-1-design.md`

## Restricciones globales

- Todo en español de España (UI, comentarios, commits).
- Solo dependencias autorizadas: `astro`, `tailwindcss`, `@tailwindcss/vite`, `mermaid`.
- Scripts de `package.json` compatibles con Windows.
- Commits en Conventional Commits, sin coautores ni menciones a herramientas.
- No relajar esquemas.

## Foco de revisión

1. Un apunte en una carpeta cuyo bootcamp no coincide con el frontmatter → error de build claro.
2. Dos apuntes con el mismo `orden` en el mismo tema → error de build claro.
3. Cambio de esquema claro/oscuro con la página abierta → Mermaid se vuelve a renderizar.
4. Título o chips muy largos en 320 px → sin scroll horizontal (tablas y código con scroll propio).
5. Bootcamp sin apuntes → la página del bootcamp muestra un estado vacío útil, no una página rota.

### Tarea 2: colecciones y contenido de prueba

**Ficheros:** `src/content.config.ts`, `src/lib/apuntes.ts`,
`src/content/bootcamps/alchemy-ethereum.json`,
`src/content/apuntes/alchemy-ethereum/pruebas/01-apunte-de-prueba.md`.

**Produce (`src/lib/apuntes.ts`):**
- `getBootcamps(): Promise<CollectionEntry<'bootcamps'>[]>` ordenados por nombre.
- `getApuntesDe(bootcampId: string): Promise<Apunte[]>` validados (coherencia ruta/frontmatter,
  `orden` único por tema).
- `agruparPorTema(apuntes: Apunte[]): Tema[]` con `Tema = { nombre, slug, apuntes }`.
- `slugDe(apunte): string` (id sin el prefijo del bootcamp).
- `vecinos(apunte, apuntes): { anterior?: Apunte; siguiente?: Apunte }` dentro del tema.
- `formatearFecha(d: Date): string` (es-ES, UTC).

- [ ] Verificar: `npm run build` → OK; con un apunte mal colocado → error con mensaje claro
  (prueba manual, se revierte).
- [ ] Commit `feat: añade las colecciones de bootcamps y apuntes` y
  `content(alchemy-ethereum): añade apunte de prueba`.
